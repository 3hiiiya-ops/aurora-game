# v76 visual and functional QA checklist

## Visual
- Trees now use a continuous custom foliage mesh, not stacks of cones.
- Snow cover follows the foliage silhouette.
- Existing cabins, rocks, mountains are still largely procedural primitive geometry; not replaced by authored 3D assets.
- Avatar is not yet identical to supplied reference artwork.

## Mobile manual checks (not run)
- Joystick movement, camera one-finger rotation, two-finger pinch zoom
- Region switching and all four regions
- Map current position, trail and zoom
- Aurora 5 minutes on / 10 minutes off per region
- Photo mode, album, chat/account where configured
- Frame rate and thermal performance on iPhone and Galaxy

Static syntax/ZIP validation is not a substitute for device QA.
